<h1 align="center">Лабораторна робота №9</h1>

---

Створити функцію на мові програмування **Python**, яка приймає дві стрічки:
* `haystack` — *(довільний текст)*
* `needle` — *(шукана стрічка)*.

> Програма повинна знайти індекси всіх входжень стрічки `needle` в стрічці `haystack` та повернути цей індекс, використовуючи **метод Кнутта-Морріса-Прата** для пошуку підстрічки у стрічці.
